This package implements leader election using an annotation in a Kubernetes object. The onstarted_leading coroutine is run as a task, which is cancelled if the leader lock is obtained and then lost.

At first all candidates are considered followers. The one to create a lock or update an existing lock first becomes the leader and remains so until it fails to renew its lease.
